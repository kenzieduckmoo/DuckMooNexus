## Findings and implemented corrections

| Area | Finding | Correction |
| --- | --- | --- |
| Sync scheduling | Large source imports shared the Journalator worker loop; Windows collection also extended the original task's runtime. | Separate source worker, lock, container name, server timer and Windows task. Existing Journalator scheduling stays intact. |
| Packet retries | ZIP member timestamps made rebuilt packets change hash despite identical content. | Fixed ZIP metadata and stable manifest serialization; regression test rebuilds under different clocks. |
| Server activation | Files were replaced individually while the timer remained enabled; failure recovery was absent. | Stage immutable modules and switch entrypoint launchers with pinned import paths. Pause timer, wait for active worker, restore launchers on activation failure, resume timer. |
| Database upgrade | Migrations committed separately; grants could fail after partial migration. | Apply 002–004 and grants in one transaction with bounded lock acquisition. Preserve 001. |
| Verification gate | Production upgrade could proceed without an integration pass. | Require a successful verification receipt matching both source fingerprint and image ID. |
| Backup/rollback | Only a nonempty dump and prose rollback instructions. | Check dump contents before upgrade; add executable server and Windows rollback. Preserve newer database rows and queued packets. Actual restore drill remains pending. |
| Grafana permissions | Most queries ran only as database owner in verification; variable queries were omitted. | Run every panel and both account selectors as Grafana role; explicitly grant required original-table columns. Check raw-archive/write access is absent. |
| Importer permissions | Real normalization was not exercised as the importer role. | Restricted-role real source imports, repeat imports, and bulk COPY in the isolated integration check. |
| Cached wallets | Unknown observation timestamps caused arbitrary selection among historical balances. | Select latest preserved file per source/character; display file save time separately from observation time. |
| Windows prerequisites | Task activation could precede detection of missing Python or collector files. | Check Python 3.13+, collector files, running state, and existing additional-task identity before registration. |
