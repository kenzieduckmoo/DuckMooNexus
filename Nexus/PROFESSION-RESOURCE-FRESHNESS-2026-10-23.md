# Independent profession resource freshness — October 23, 2026

Omni Capture 0.1.4 records a naturally opened profession's concentration currency identity, amount, cap, available regeneration rate and resource observation time. Known pool IDs are retained for subsequent currency reads even when that profession closes. Currency events update the pool only; they do not rescan trait trees or advance the older knowledge observation time. Unavailable reads retain the prior resource and its own timestamp. The addon remains independent from the crafting scanner, with its own settings, SavedVariables and event lifecycle.

The profession board accepts a newer valid pool directly from that explicit child-skill/currency mapping, including characters without a Planner sample. The shared Crafting Desk importer merges newer Omni profession metadata and resource observations by GUID, skill-line ID and exact currency ID. Zero is valid, wrong currency IDs are ignored, and invalid or older resources do not erase an earlier valid pool. A resource observation cannot establish recipe ownership, output quality or a captured crafting outcome.

The hosted model now obtains these identity/profession/resource sections from the normalized Omni view in PostgreSQL, through the existing crafting service role. Migration 018 grants that role SELECT on the current view; it already has access to archived source data. Refresh signature advanced to crafting-0.9.2 so the new model is generated even if source IDs have not changed. Existing cache/source copies are retained for rollback. Saved plans, setups, raw archives and historical observations are not rewritten by this refresh.

Focused checks cover a real-zero pool refresh with the profession closed, unchanged knowledge timestamps, matched currency IDs, newer/invalid resource selection and full importer assembly without inferred recipes. The new addon path is mocked; its next actual client save remains a separate gate. Production deployment and observed model-source verification are recorded below when complete.
