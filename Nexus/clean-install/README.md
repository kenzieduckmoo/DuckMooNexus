# DuckMoo Nexus 0.4.0 — clean install

Extract this release on your Windows gaming PC. Run in PowerShell:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-Nexus.ps1 -SavedVariables "C:\Program Files (x86)\World of Warcraft\_retail_\WTF\Account\YOUR_ACCOUNT\SavedVariables"
```

The server defaults to `kenzieduckmoo@10.20.30.239`. Add `-Server hostname -AdminUser username` if different. Enter the Ubuntu SSH/sudo password when requested. No manual database, environment-file, Docker, Grafana, or task setup is needed. Python 3.11+ and Windows OpenSSH must be available on the Windows PC; Ubuntu needs internet access for packages and container images.

The installer intentionally uses password authentication for administrator setup because the existing sync key is restricted to uploads. If you have an unrestricted administrator key, add `-AdminIdentity "C:\path\admin-key"` instead.

Optional: add `-HistoricalSnapshots "C:\path\extracted-source-snapshots"` to import the existing historical `.json`/`.lua.gz` archive as well. The original history remains untouched. Add `-TsmAppData "D:\path\TradeSkillMaster_AppHelper\AppData.lua"` only if its normal location cannot be inferred.

The command replaces the clean-install database and Grafana volumes on every installation, retires the old Nexus timers and matching Nexus containers, builds the importer, initializes PostgreSQL 17, provisions both dashboards, uploads current SavedVariables and `.bak` copies, and registers invisible five-minute sync. Retained packets from earlier clean installations are reimported automatically. It does not reinstall Ubuntu or delete original SavedVariables, historical snapshots, old source spools, or unrelated Docker volumes.

Installation reports success only after source records exist in PostgreSQL, both **Warband Financials** and **Azeroth Stock Exchange** are provisioned, Grafana's datasource health check passes, and the scheduled task is registered. The generated Grafana admin password is printed at the end of verification. Open `http://10.20.30.239:3000` (or your selected server).

Windows sync runs while you are signed in, including with the screen locked. It uses WScript to create no visible console and returns PowerShell's actual exit code to Task Scheduler. Inspect `%LOCALAPPDATA%\DuckMooNexusClean\state\last-result.json` or `sync.log` for failures; Task Scheduler's **Last Run Result** is nonzero on failure. Retry manually with:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\DuckMooNexusClean\Sync-Nexus.ps1"
```

Source snapshots are compressed and retained locally and on the server. An upload acknowledgement means the source was archived in PostgreSQL and its supported adapter completed. Unsupported normalization sources remain raw archives, not invented records. Collector/parser/SSH/database failures stop the run and preserve the packet for retry. Credentials are generated by the installer, not embedded in this release.
